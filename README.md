# Fake-Drug-Text
NAFDAC Product Verification System  This project develops an interactive system to verify NAFDAC product numbers, aiming to help identify genuine, cloned, or potentially counterfeit products. It integrates data collection, cleaning, and a simulated real-world verification pipeline to provide instant verdicts.
using  rule-based algorithm i.e Deterministic Regex Parsing with Conditional Branching
including 2FA (Two-Factor Authentication) for users or Two-Step Product Verification, cause counterfeiters can easily print a real, valid NAFDAC number onto a fake bottle, a single check of the number on the bottle is never enough.
